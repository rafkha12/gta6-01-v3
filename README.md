Bahía Sol — an open-world crime game in the spirit of GTA 6: a sun-soaked sunset city to explore on foot and by car, with traffic, police, missions and a story.

Drive into the sunset as Mara Voss or Dario Cruz, two drivers running jobs for the fixer Rosa Delmar. Steal cars, lose the police, deliver the package, and bring the money home — across a purple-pink dusk city with palms, neon signs, a beach and a marina.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No network requests, no build step.

## Controls

WASD move · mouse drag camera · Shift run · E enter / exit car · F punch · M job · P pause
